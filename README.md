# 🤖 *Robo Copy Project*
UE5와 C++을 기반으로 게임 로보퀘스트의 기능을 모작한 FPS RPG 프로젝트
<br />
<br />
<br />
***
### ✅ 주요 기능
+ Roboquest의 전투 구조를 분석하여 FPS 전투 시스템과 데이터 기반 장비 적용 구현
+ Unreal Engine의 Replication 및 RPC를 활용하여 서버 권한 기반(Server-Authoritative) 상태 동기화 구현
+ 전투, 무기 Equip 시스템, 몬스터 스폰, 서버-클라이언트 동기화 구조 설계 및 구현
<br />
